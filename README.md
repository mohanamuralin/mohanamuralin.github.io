# Kalpyo website

Public website for Kalpyo and its apps, served by GitHub Pages at
**https://mohanamuralin.github.io/**.

| Page | URL |
|---|---|
| Kalpyo home | https://mohanamuralin.github.io/ |
| TrackOR | https://mohanamuralin.github.io/trackor/ |
| TrackOR privacy policy | https://mohanamuralin.github.io/trackor/privacy.html |
| TrackOR support | https://mohanamuralin.github.io/trackor/support.html |

The privacy and support URLs are linked from inside the TrackOR app and from
the App Store / Google Play listings, so **don't rename or move those files**.
Add future apps as new folders (for example `/nextapp/privacy.html`).

Plain static HTML and CSS; no build step. `.nojekyll` makes GitHub serve the
files as-is.
